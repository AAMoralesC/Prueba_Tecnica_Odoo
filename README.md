# Prueba Técnica Odoo v18

Solución a los requerimientos técnicos solicitados. Este repositorio contiene dos módulos personalizados:

1. **`sale_customer_rut_display`**: Muestra el RUT del cliente en el formulario y lista de pedidos de venta, permitiendo filtrar y ordenar.
2. **`partner_pay_term`**: Asigna "Pago Inmediato" a clientes nuevos por defecto, bloquea la edición del término de pago a usuarios sin perfil contable y registra los cambios en el Chatter.

Dentro de la carpeta de cada módulo encontrarán su respectivo README con las instrucciones de uso y las capturas de pantalla evidenciando que se cumplen todos los criterios de QA.
